# 🍎 Apple Catcher

A simple 2D arcade game made with Python and Pygame.

In this game, the player controls a basket and catches falling apples. The goal is to catch as many apples as possible while avoiding misses.

## 🎮 Features

- 🍎 Falling apples
- 🧺 Player-controlled basket
- ❤️ 3 lives
- 📈 Increasing difficulty
- ⚡ Apple speed increases as lives are lost
- 🏆 Score tracking
- 🎮 Simple keyboard controls
- 🌳 Colorful game environment

## 🕹️ Controls

| Key | Action |
|-----|--------|
| ← Left Arrow | Move basket left |
| → Right Arrow | Move basket right |
| SPACE | Start / Restart the game |
| ESC | Quit the game |

## 🛠️ Technologies Used

- Python
- Pygame
